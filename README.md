## 🤝 The Concept
Everyday exchanges between friends, neighbors, and local Caribbean SMBs often feel cold and fragmented. **BizPay** is a static frontend UI prototype exploring how community payments, on-site/online transactions, and multi-tier employee payroll management could look in a mobile-first web dashboard inspired by ATH Móvil Business.

---

## ⚙️ The Technology
- **HTML5 & Material Design Lite (MDL 1.2.1):** Responsive drawer layout, expandable search bar, data tables, and native `<dialog>` interaction across `index.html`, `Pages/Payments.html`, `Pages/Payroll.html`, and `Pages/Fulltime-details.html`.
- **Bootstrap & Custom CSS:** Responsive grid columns (`container`, `row`, `col-md-*`) paired with custom dashboard styling (`BizPay/styles.css`).
- **Vanilla JavaScript & jQuery:** Smooth anchor scrolling, hover state helpers, and modal triggers (`BizPay/Assets/JS/script.js` and inline page scripts), plus Add-to-Home-Screen metadata.

---

## 🌱 The Impact
- Explores an accessible, low-friction payment and payroll UX tailored for small businesses and community micro-economies in Puerto Rico.
